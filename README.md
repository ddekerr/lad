# Лад

Веб-застосунок для музикантів: база пісень з текстом і акордами, плейлисти під музичні ролі, персональні копії, транспонування, режим сцени. Адаптивний (телефон, планшет, комп'ютер), інтерфейс англійською за замовчуванням і українською.

## Швидкий старт

Потрібні Node.js 20+ і PostgreSQL.

```bash
npm install
cp .env.example .env          # заповни значення: див. docs/technical.md, розділ 5.2
npx prisma migrate dev
npm run db:seed               # ролі й три демо-пісні
npm run dev                   # http://localhost:3000
```

Без налаштованого SMTP код для входу друкується в консоль, де запущено `npm run dev`. Вкажи свою пошту в `SUPER_ADMIN_EMAIL`, увійди нею, і ти отримаєш права адміна й супер-адміна.

Перевірки перед пул-реквестом: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.

## Статус

Готово: каталог і перегляд пісні, транспонування, режим сцени, вхід (Google й email-код), ролі й права, плейлисти, персональні копії з оновленням з оригіналу, редактор пісень, імпорт із JSON.

Далі: перевірка в живому середовищі (`npm install`, міграції, e2e-тести), партії для інструментів (див. [посібник](docs/musicians-guide.md), розділ 12), імпорт в інших форматах.

Код розроблявся без запуску Next.js і Prisma (у середовищі розробки був закритий npm), тому перший повний прогін може виявити дрібні помилки.
