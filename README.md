# Лад

Веб-застосунок для музикантів: база пісень з текстом і акордами, плейлисти, персональні копії, режим сцени. Адаптивний (телефон, планшет, комп'ютер), інтерфейс англійською за замовчуванням з перемикачем на українську.

Вимоги, схема БД і структура бекенду лежать у Project «Лад» (`lad-functional-spec.md`, `lad-db-schema.md`, `lad-backend-spec.md`, `lad-brand-spec.md`).

## Стек

Next.js (App Router, TypeScript), Tailwind CSS 4, PostgreSQL + Prisma.

## Запуск

```bash
npm install
cp .env.example .env
docker compose up -d          # PostgreSQL на порту 5432
npx prisma migrate dev --name init
npm run db:seed               # ролі й три демо-пісні
npm run dev                   # http://localhost:3000
```

Тести логіки акордів: `npm test`. Перевірка типів: `npm run typecheck`.

## Статус

Етап 1 (поточний):
- каркас, бренд-тема (токени, Unbounded + Onest), EN/UK;
- схема БД повністю за специфікацією;
- каталог пісень із пошуком, перегляд пісні (текст / акорди / обидва), зміна тональності з автоматичним транспонуванням, режим сцени;
- публічні API `GET /api/songs` і `GET /api/songs/{id}`.

Далі: етап 2 (вхід через Google і email-код, ролі), етап 3 (плейлисти й копії), етап 4 (редактор пісень, адмінка).

## Примітки

- Транспонування працює на клієнті (`src/lib/chords`), покрите тестами.
- Етап 1 написано без запуску Next.js і Prisma (у середовищі розробки був закритий npm), тому перший `npm install`, `migrate` і `dev` можуть виявити дрібні помилки.
