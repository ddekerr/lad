# ub-mode tools

Три маленькі скрипти для перевірок із ub-mode. Залежать лише від `typescript` і `tsx` з проєкту, нічого не змінюють у коді (крім мутатора, який тимчасово ламає один файл і повертає його назад).

| Команда | Що робить |
| --- | --- |
| `npm run ub:coverage` | Запускає тести з покриттям у `coverage/lcov.info` (потрібно для crapper). |
| `npm run ub:crap [поріг] [кількість]` | CRAP кожної функції: складність² × (1 − покриття)³ + складність. Від 10 і вище: розбити або покрити тестами. |
| `npm run ub:dry [рядків]` | Шукає скопійований код: однакові блоки від N рядків (за замовчуванням 8) у різних файлах. |
| `npm run ub:mutate -- <файл> <тест>` | Ламає оператори (`>=` на `>`, `true` на `false`…) і запускає тест. Мутант, що вижив, означає слабкий тест. |

Приклад: `npm run ub:mutate -- src/entities/setlist/model/setlist-order.ts src/entities/setlist/model/setlist-order.test.ts`.

Обмеження: це спрощені версії. Мутатор не перевіряє типи, тому зміни в типах (`-1 | 1`) виживають як еквівалентні мутанти. Для глибшої перевірки є Stryker, jscpd і правило `complexity` в ESLint.
